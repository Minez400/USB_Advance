# Política de Segurança - USB Advance

A segurança e a proteção dos dados dos usuários são prioridades absolutas no desenvolvimento do **USB Advance**. Como este aplicativo lida diretamente com operações destrutivas em nível de bloco de armazenamento, qualquer falha potencial que possa afetar mídias internas do sistema é tratada com severidade máxima.

---

## 🔒 Relatando Vulnerabilidades

Se você encontrar uma vulnerabilidade de segurança (especialmente relacionada a desvios de nós de bloco ou acesso indevido à memória interna), **não abra uma issue pública**.

Envie os detalhes técnicos diretamente para a equipe mantenedora:
* **E-mail de Segurança**: `security@usbadvance.org` (ou através de Security Advisory privado no GitHub).

Inclua:
1. Descrição detalhada da vulnerabilidade.
2. Modelo do smartphone, versão do Android e se o aparelho possui Root.
3. Passos exatos para reprodução.
4. Código de prova de conceito (PoC), se disponível.

Responderemos em até 48 horas e trabalharemos em um patch de segurança antes de qualquer divulgação pública.
